# Extore 商品资料导入

卖家中心 `/store/manage` 提供“从 Extore 导入”。当前实现是原生 JSON 文件／粘贴导入，不是在线 OAuth 客户端；不会请求授权、读取远端目录、刷新令牌或发行卡密。

## 使用

1. 在 Extore 复制或导出商品资料。支持 `extore.product-listing.v1` 单个商品，以及 `extore.commerce-catalog.v1` 商品目录；也接受单独的 JSON 代码块。
2. 打开卖家中心的“从 Extore 导入”。自建 Extore 时，展开“Extore 地址”修改 base URL。默认 `https://extore.lmm.best`。成功解析资料后，地址按当前账号保存在此浏览器中，不保存任何凭据，也不会更改其他账号的设置。
3. 选择文件或粘贴 JSON，预览商品与规格。每次将一个启用的规格导入为一个独立草稿。停用规格不可选。
4. 另行填写本站售价并确认标题。价格输入复用商城已有的货币换算逻辑，不把 Extore 参考价直接作为本站售价。
5. 保存后，在卖家中心完成支付和库存配置，按现有流程提交审核。导入不自动上架，不增加库存。

## 字段与边界

标题、介绍、可选图片、联系信息和所选规格介绍映射到现有商品字段。兑换链接及源店铺、商品、规格、资料版本标识保存到商品的 Extore 链接说明中；这是来源信息，不是已验证的服务器关联或同步凭据。

参考价保留原始十进制文本与币种用于预览；未知价格保持未知。`remaining`、`available`、发行额度和上游卡密数量不会成为本站库存。

输入定义、输出定义、权益属性等未转换字段在“来源详情”中列出。原始商品资料可另存 JSON；它们不会被静默改成商城发货内容。原始完整 JSON 不会上传到商品数据库，不能将这个文件导入功能当作自动同步或补货连接。

数据大小上限 2 MiB，每目录最多 100 个商品，每商品最多 100 个规格。拒绝不匹配的目录来源、跨店铺资料、重复标识、不支持的格式和失效规格。图片缺失或 URL 不可用时不制造占位图片。

## 在线授权尚未接入

在线实现应遵循 Extore 的 `extore.commerce-import.v1` 协议：服务端保存账户绑定的一次性 state 与 S256 PKCE verifier，校验发行者及固定端点，只申请 `products.read`，拒绝重复或过期回调，并在服务端保护令牌。`cards.issue`、幂等补货和卡密入库是独立功能，不能用读取商品的按钮隐式授权。

协议依据：<https://github.com/TokenNotIncluded/extore/blob/main/docs/commerce-import-protocol.md>。
